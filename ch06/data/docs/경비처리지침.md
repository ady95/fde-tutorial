# 경비 처리 지침 (한빛제조 재무팀, 2025-11 개정)

## 법인카드 사용
- 법인카드는 업무 목적에만 사용하며, 사용 후 7일 이내 그룹웨어에 증빙을 등록한다.
- 1회 30만 원 이상 사용 시 사전 품의가 필요하다.
- 주류가 포함된 회식비는 팀장 승인이 있어야 한다.

## 식비
- 야근 식비는 1인 1만 5천 원 한도로 지원한다 (20시 이후 퇴근 시).
- 휴일 근무 시 중식·석식 각 1만 5천 원을 지원한다.

## 교통비
- 시내 이동은 대중교통을 원칙으로 하고, 택시는 22시 이후 또는 긴급 시에만 인정한다.
- 자가용 업무 사용 시 km당 500원의 유류비를 지급한다.

## 증빙 규칙
- 모든 경비는 카드 전표 또는 세금계산서를 첨부해야 한다.
- 간이영수증은 3만 원 이하만 인정한다.
