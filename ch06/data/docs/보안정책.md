# 정보보안 정책 (한빛제조 정보보안팀, 2026-02 개정)

## 계정과 비밀번호
- 비밀번호는 12자 이상, 90일마다 변경한다.
- 퇴사자 계정은 퇴사일 당일 비활성화한다.
- 계정 공유는 사유를 불문하고 금지한다.

## 데이터 등급
- 1등급(대외비): 설계 도면, 고객 계약서 — 암호화 저장, 외부 반출 금지
- 2등급(내부용): 회의록, 내부 보고서 — 사외 공유 시 팀장 승인
- 3등급(공개): 홍보 자료, 채용 공고

## 외부 서비스 사용
- 승인되지 않은 클라우드 서비스에 회사 데이터를 업로드할 수 없다.
- 생성형 AI 서비스에 1·2등급 데이터를 입력하는 것을 금지한다.
- 신규 SaaS 도입은 정보보안팀 사전 심사를 거친다.

## 사고 대응
- 보안 사고 인지 시 1시간 이내 정보보안팀(내선 5555)에 신고한다.
